# TqkLibrary.Http.Utils

API clients built on [TqkLibrary.Http](https://github.com/tqk2811/TqkLibrary.Http): captcha, cloud storage (Dropbox, Google Drive, OneDrive), Google Docs, mail, phone, proxy and others.

## Clone

```
git clone --recurse-submodules https://github.com/tqk2811/TqkLibrary.Http.Utils.git
```

`TqkLibrary.Http` is included as a git submodule; open `src/TqkLibrary.Http.Utils.sln`.
